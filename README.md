🎬 Movie Review Text Analytics Dashboard

📌 Project Overview

- This project analyzes 50,000 movie reviews using Power BI. The dashboard provides insights into word frequency patterns, sentiment distribution, review length analysis, and noise classification.
- All data cleaning, transformation, modeling, and visualization were performed entirely within Power BI.

🎯 Objectives

- Perform text preprocessing within Power BI
- Analyze word frequency across sentiments
- Compare positive and negative reviews
- Evaluate review length distribution
- Classify review noise types
- Build an interactive analytics dashboard

🛠 Tools Used

- Microsoft Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Calculated Measures & KPIs)
- Data Modeling

📊 Dashboard Components

- 🔢 Total Reviews (50K)
- 📈 Maximum Word Count (2468)
- 📊 Average Word Count (358)
- 📝 Word Frequency by Sentiment
- 📚 Unigram Analysis
- 😊 Sentiment Distribution
- 📏 Review Length Analysis
- 🔍 Noise Type Classification

📈 Key Insights

- The dataset consists of 50,000 movie reviews.
- Positive and negative sentiments are nearly balanced.
- Average review length is 358 words.
- Majority of reviews fall under the "Normal" length category.
- Commonly used words indicate descriptive review patterns.

💼 Business Value

This dashboard helps:
- Understand audience sentiment trends
- Identify dominant word usage patterns
- Evaluate review quality and length behavior
- Support content quality analysis
- Assist in decision-making for entertainment platforms

🚀 Future Enhancements

- Stopword removal for cleaner NLP results

- Advanced filtering options
